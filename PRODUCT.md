# KommitEye

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Administrators configure repository reviews and mail delivery. Commit authors read their own reviews and respond to individual findings.

## Product Purpose

Review Git commits and let authors acknowledge bugs or identify false positives with optional comments.

## Capabilities and Constraints

The author portal belongs to Service/Web. Authors sign in by email code and only see reviews attributed to that email. Administrators configure code expiry, resend limits, attempts, lockout and session lifetime. Mail settings control author notifications and optional false-positive alerts to administrators. New commits are reviewed independently; the product does not track fixes or close earlier findings automatically.

## Brand Commitments

Extend the existing KommitEye interface and its Russian/English copy.
